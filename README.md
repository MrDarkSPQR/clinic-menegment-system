# clinic-management-system
## Система обліку пацієнтів та запису на прийом у невеликій клініці

### Про проєкт
Це система для невеликих приватних клінік або окремих медичних кабінетів, яка замінює паперові журнали та таблиці в Excel. Вона складається з двох частин: звичайної комп'ютерної програми для працівників клініки та вебсайту, через який пацієнти можуть самі записатися на прийом.

Головна фішка проєкту — програма в клініці може спокійно працювати без інтернету. Всі картки пацієнтів і розклад зберігаються прямо на комп'ютері. Коли з'являється мережа, програма сама з'єднується з сайтом і завантажує нові онлайн-записи. Також у програму вшитий пробний період на 3 дні, щоб клініка могла протестувати її перед покупкою повноцінної ліцензії.

### Основні можливості
* **База пацієнтів:** електронні картки з контактами та історією всіх попередніх візитів.
* **Розумний розклад:** зручний графік роботи лікарів, який не дає випадково записати двох людей на один і той самий час.
* **Онлайн-запис:** проста форма на сайті для пацієнтів та автоматичне перенесення цих заявок у комп'ютерну програму.
* **Контроль ліцензії:** прив'язка програми до конкретного комп'ютера та перевірка 3-денного безкоштовного доступу через сервер.

### Потенційні ролі в команді
* **Backend-розробник:** відповідає за базу даних, серверну логіку синхронізації та систему перевірки ліцензій.
* **Desktop / Frontend-розробник:** створює віконний інтерфейс програми для клініки та сторінку запису на сайті.
* **Тестувальник (QA):** перевіряє роботу програми без інтернету, правильність перенесення записів та захист пробного періоду.
